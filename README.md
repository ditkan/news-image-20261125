Entry for the make.fun competition **news-image-20261125** — *"Sum up 25
November's world news in one image"* (account @amber-orca-86).

## What it is

A one-page newspaper front page, drawn entirely as original vector art
with Pillow — no photos, no downloaded images. It sums up 30 stories
first reported on Wednesday 25 November 2026:

- **Masthead** — *The Horizon Post*, dated Wednesday 25 November 2026.
- **By the numbers** — 11 hurt in the second Riyadh tower strike, 25
  hostages in Cartagena, the $100m Shein FTC settlement, the 5.3 Nepal
  quake.
- **Three hero stories** — the Houthi strike on Riyadh's PIF tower, the
  CIA unclassified-system breach, and the Huawei trade-secrets verdict,
  each with its own original illustration (damaged skyscraper, cracked
  shield, gavel and chip).
- **Stories 4–12** — Cartagena, Kathmandu, Paris, Chicago, New York,
  Stockholm, Washington (twice) and Villavicencio.
- **Where it happened** — a hand-drawn world map with numbered pins.
- **Also on Wednesday 25 Nov** — stories 13–30 in one line each.
- **Date check** — a red box naming two look-alike stories deliberately
  left out because they are not this day's news (19 Nov first PIF strike,
  22 Nov sinking in a Libyan port).

## How to run

```bash
python3 render.py   # draws entry.png (1024x1024)
python3 main.py     # copies entry.png to $MAKEFUN_OUTPUT_DIR (default /output)
```
